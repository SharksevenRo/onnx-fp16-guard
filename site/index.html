onnx-fp16-guard

Safe float16 conversion for ONNX — half the download, no quality loss, and no silent clamping.

Open the live demo Source on GitHub

What it does

  • Inspects every float tensor — initializers and payloads embedded in Constant nodes — for values outside ±65504.
  • Repairs overflowing BatchNorm layers with an exact power-of-two rescale (var /= K², scale /= K, epsilon /= K²), so the layer computes the same function.
  • Converts float32 → float16 with round-to-nearest-even, bit-exact against NumPy's astype(np.float16).
  • Keeps the graph valid: ops without fp16 kernels stay fp32, int64 plumbing is left alone, casts are placed where the dtypes actually differ.

Install

npm install onnx-fp16-guard
npx onnx-fp16-guard inspect model.onnx

Or run it right here

The demo on this site is the exact library, pre-bundled for the browser. Drop an .onnx file on the page: it is inspected and converted locally — the model never leaves your machine.
